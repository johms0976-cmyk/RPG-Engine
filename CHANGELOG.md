# Changelog

The changelog lives at **[`docs/CHANGELOG.md`](docs/CHANGELOG.md)**.

This file used to be a second copy of it. The copy stopped being updated at 2.0.0 and stayed in
the repository root for eleven releases, so the first changelog a reader found was the one that
was four years of work out of date. A duplicate that drifts is worse than no duplicate: it does
not merely fail to inform, it actively misinforms, and it does so to exactly the person who is
looking hardest.
