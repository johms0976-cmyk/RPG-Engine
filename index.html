You are looking at the raw source, not a build. This page is asking for src/main.jsx, which no browser can run directly — it has to be compiled by Vite first.

If this is GitHub Pages: open Settings → Pages → Build and deployment and set Source to GitHub Actions, then run the Deploy to GitHub Pages workflow from the Actions tab.

If this is your own machine: run npm install then npm run dev, and open the address it prints. Opening index.html straight off disk will not work either.
